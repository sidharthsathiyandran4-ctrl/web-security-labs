# Web Security Labs

Write-ups of hands-on labs from [PortSwigger Web Security Academy](https://portswigger.net/web-security), completed for learning purposes.

All labs are intentionally vulnerable applications provided by PortSwigger. No real systems were tested.

## What each write-up covers

- **Summary** of the vulnerability
- **How I found it** and the steps to exploit it
- **Why it works** (the root cause)
- **Impact** and **Fix**
- **What I learned**

## Tools used

- Burp Suite Community Edition
- Web browser

## Disclaimer

This repository is for educational purposes only. Only test systems you own or have explicit permission to test.

I'm learning web application security and documenting what I learn as I go.
